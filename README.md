# Lesotho Tourism Web Application

## Project Description
An interactive tourism web application for Lesotho, built with React.js. It helps local and international visitors discover tourist attractions, activities, and cultural experiences available in Lesotho.

## Technologies Used
- React.js
- React Hooks (useState)
- CSS3
- JavaScript (ES6)
- HTML5

## Features
- Home page with hero, about, featured destinations, and popular activities
- Attractions page with 8 destinations displayed dynamically
- Search attractions by name
- Filter attractions by category
- Attraction details modal with activities and estimated cost
- Visitor enquiry form with full JavaScript validation
- Responsive design for desktop, tablet, and mobile
